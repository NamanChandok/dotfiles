# Arch dotfiles

**OS:** Arch Linux

**DM:** GNOME

**Browser:** Zen

**IDE:** Zeditor

**Terminal:** Kitty

**Shell:** ZSH

**Icon Theme:** [WhiteSur Alternate](https://github.com/vinceliuice/WhiteSur-icon-theme)

**GTK Theme:** [WhiteSur](https://github.com/vinceliuice/WhiteSur-gtk-theme)

**Cursor:** [Polarnight](https://github.com/yeyushengfan258/Polarnight-Cursors)

**Font:** FiraMono Nerd Font, Adwaita Sans

**List of GNOME Extensions:**
- Alphabetical App Grid
- AppIndicator and KStatusNotifierItem Support
- BlurMyShell
- Caffeine
- Clipboard Indicator
- Color Picker
- Dash to Dock
- Media Controls
- moveclock
- Open bar
- User Themes
- Window title is back
